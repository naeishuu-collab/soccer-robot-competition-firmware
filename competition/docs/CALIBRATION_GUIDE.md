# OpenMV校正ガイド

`camera_calibration.py` はPR #6の基準値。QVGA 320×240、中心 (171,129)、環 (29,77) px、前方86°、`CLOCKWISE=False`。床距離対応は (50px,18cm)、(74px,50cm)。露光45,000µs、ゲイン6dB。白バランスは初期調整後に固定する。前方86°と中心・床距離は現物で検証する。

1. 同じ高さ・ミラー位置で前後左右に物体を置き、角度が0・180・270・90°になることを確認する。前方は画像の上から時計回りに測る。実機の既存値が正しい場合は記録した値を使う。
2. 既知の距離に線を置き、距離補間を確認する。この距離表の18cm未満は観測対象外。死角まで進む前に検知・停止できる距離を測る。
3. 試合場の白、緑、黄、青のLAB値を複数方位と明暗で採取する。照明、ミラー反射、斜め方向、白い機体も確認する。
4. 両ゴールはミラーリング内のLAB領域を探索し、見かけの角幅、弧／高さ、密度と向こう側の芝で候補を評価する。ゴール距離は未校正のため、方位と品質を送る。 `TARGET_GOAL` はハーフごとに設定する。
5. OpenMV USBで `l` は白線のみ、`b` は毎フレーム両色、`g` は試合設定（60ms以上の間隔で交互に1色、重い探索後は160ms）。同じ照明・構図で各30秒の capture、line、UART、goal、total の最大値とFPS、連続パケットの間隔を比較する。USB `i` は詳細を即時要求。測定値はOpenMVの [USB VCP](https://docs.openmv.io/v4.8.1/library/pyb.USB_VCP.html) から取得。

ゴール探索は白線パケットの送信後に実行し、検出値を次のパケットから送る。ゴールの有効期限は300ms。45ms露光による理論上限は約22 FPSで、センサーの実露光・転送・処理を含むFPSは要測定。起動時にRGB565 LUTを作り、実フレーム3枚の走査点が参照処理に一致する場合だけ高速走査を使う。

## IDE表示と比較設定

VISUALIZATION_MODE は LIGHT が既定。USBの 0／1／2 で OFF／LIGHT／FULL に切り替える。LIGHT は現フレームの黄・青枠、中心、方位と信頼度、最近白線の位置・距離、退避矢印とFPS。FULL はミラー内外周と前方、全白線、16セクター、キャッシュされたゴール方位も表示。緑は観測済み安全、赤は白線で閉鎖、灰色は未確定。過去の認識に枠を描かない。画像認識とUART送信後に描画し、LIGHTは約25回/s以下、FULLは約10回/s以下。

GOAL_X_STRIDE は既定1。2は遠い小ゴールを落とす可能性があるため比較用。既定探索はミラー外接矩形内の重なる4帯、直前の検出周辺、8回ごとの全リング再探索。帯の縁で途切れた候補は見送る。USBの h は黄青交互の全リング検索。d は次の余裕があるフレームで黄の直近ROIをストライド2、最低1画素で調べる。raw が0なら画角またはLAB、small が多ければ最小画素数、clip／ring／shape／turf は各除外条件を確認。i は実露光の取得値、ROI、最低画素数、除外数を表示する。

BENCH_EXPOSURE_US は 45000、30000、20000、15000、10000、5000 から選べる。BENCH_GAIN_DB はゲインの比較用。BENCH_WINDOW の (80,48,176,168) はQVGAと同じ画素密度で切り出し、ドライバーが返す実際の位置から中心を平行移動する。ミラー外周を失う設定では安全マスクを作れない。ベンチ設定中はUARTのREADYを落とす。基準はQVGA、露光45,000µs、6dBと既存LAB。短露光ではノイズと白線・各ゴールの検出率を測り、別校正プロファイルに保存する。

USBの各計測値は平均／P95の4msビン上端／最大をµsで表示。白線と緑床は同じネイティブ走査で判定するため LINE_FLOOR として一括計測する。CAPTURE にはセンサー待ちとファームウェア側のプレビュー処理が含まれうる。IDE画像は接続なし、JPEG、画像転送OFF、描画OFFを比較し、PC画面までの遅延は別途測る。画像転送停止はIDEビューアの Disable を利用できる。 [OpenMVのプレビュー仕様](https://docs.openmv.io/v5.0.1/openmvcam/tutorial/vision/csi/ide-preview.html)
