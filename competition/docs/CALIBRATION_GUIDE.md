# OpenMV校正ガイド

`camera_calibration.py` はPR #6の基準値。QVGA 320×240、中心 (171,129)、環 (29,77) px、前方86°、`CLOCKWISE=False`。床距離対応は (50px,18cm)、(74px,50cm)。露光45,000µs、ゲイン6dB。白バランスは初期調整後に固定する。前方86°と中心・床距離は現物で検証する。

1. 同じ高さ・ミラー位置で前後左右に物体を置き、角度が0・180・270・90°になることを確認する。前方は画像の上から時計回りに測る。実機の既存値が正しい場合は記録した値を使う。
2. 既知の距離に線を置き、距離補間を確認する。この距離表の18cm未満は観測対象外。死角まで進む前に検知・停止できる距離を測る。
3. 試合場の白、緑、黄、青のLAB値を複数方位と明暗で採取する。照明、ミラー反射、斜め方向、白い機体も確認する。
4. 両ゴールはミラーリング内のLAB領域を探索し、見かけの角幅、弧／高さ、密度と向こう側の芝で候補を評価する。ゴール距離は未校正のため、方位と品質を送る。 `TARGET_GOAL` はハーフごとに設定する。
5. OpenMV USBで `l` は白線のみ、`b` は毎フレーム両色、`g` は試合設定（同一フレームで両色をまとめ、45ms以上の間隔、重い探索後は160ms）。同じ照明・構図で各30秒の capture、line、UART、goal、total の最大値とFPS、連続パケットの間隔を比較する。USB `i` は詳細を即時要求。測定値はOpenMVの [USB VCP](https://docs.openmv.io/v4.8.1/library/pyb.USB_VCP.html) から取得。

ゴール探索は白線パケットの送信後に実行し、検出値を次のパケットから送る。ゴールの有効期限は300ms。45ms露光による理論上限は約22 FPSで、センサーの実露光・転送・処理を含むFPSは要測定。起動時にRGB565 LUTを作り、実フレーム3枚の走査点が参照処理に一致する場合だけ高速走査を使う。

## IDE表示と比較設定

VISUALIZATION_MODE は LIGHT が既定。USBの 0／1／2 で OFF／LIGHT／FULL に切り替える。LIGHT は現フレームの黄・青枠、中心、方位と信頼度、最近白線の位置・距離、退避矢印とFPS。FULL はミラー内外周と前方、全白線、16セクター、キャッシュされたゴール方位も表示。緑は観測済み安全、赤は白線で閉鎖、灰色は未確定。過去の認識に枠を描かない。画像認識とUART送信後に描画し、補助描画の最短間隔はLIGHTが20ms、FULLが100ms。新規検出枠はこの間隔に関係なく描く。

GOAL_X_STRIDE は既定1。2は遠い小ゴールを落とす可能性があるため比較用。既定探索はミラー外接矩形内の重なる4帯、直前の検出周辺、4回ごとの全リング再探索。帯の縁で途切れた候補は見送る。USBの h は黄青をまとめた全リング検索。d は次の余裕があるフレームで黄の直近ROIをストライド2、最低1画素で調べる。raw が0なら画角またはLAB、small が多ければ最小画素数、clip／ring／shape／turf は各除外条件を確認。i は実露光の取得値、ROI、最低画素数、除外数を表示する。

BENCH_EXPOSURE_US は 45000、30000、20000、15000、10000、5000 から選べる。BENCH_GAIN_DB はゲインの比較用。BENCH_WINDOW の (80,48,176,168) はQVGAと同じ画素密度で切り出し、ドライバーが返す実際の位置から中心を平行移動する。ミラー外周を失う設定では安全マスクを作れない。ベンチ設定中はUARTのREADYを落とす。基準はQVGA、露光45,000µs、6dBと既存LAB。短露光ではノイズと白線・各ゴールの検出率を測り、別校正プロファイルに保存する。

USBの各計測値は平均／P95・P99の4msビン上端／最大をµsで表示。白線走査は WHITE_SCAN。緑床認識は走行許可に使わない。CAPTURE にはセンサー待ちとファームウェア側のプレビュー処理が含まれうる。IDE画像は接続なし、JPEG、画像転送OFF、描画OFFを比較し、PC画面までの遅延は別途測る。画像転送停止はIDEビューアの Disable を利用できる。 [OpenMVのプレビュー仕様](https://docs.openmv.io/v5.0.1/openmvcam/tutorial/vision/csi/ide-preview.html)


## 20・30・45cmの距離校正

1. 動力を切り、鏡とカメラは競技時と同じ位置で固定する。`BENCH_DISTANCE_CM = 20`、`VISUALIZATION_MODE = "LIGHT"` で起動し、1つのテープ目印だけを定規の20cm位置に置く。30cmでも繰り返す。方向は機体正面付近。ベンチ中はUART READYが立たない。
2. 45cmでは定規・テープを片付け、実際の白線だけを使用する。機体中心から白線の手前の縁を測り、`BENCH_DISTANCE_CM = 45` で記録する。水色枠は白色領域候補、赤枠は通常スキャンの確定領域。定規上のテープと実際の白線を同時に校正点として拾わない。
3. IDEのログから `MIRROR_CENTER`、各 `TARGET_XY`／`PIXEL_RADIUS`、補間区間 `SEGMENT`、範囲内かを示す `DISTANCE_VALID` を記録する。最大3候補なので表示された枠と照合する。白線の手前縁は通常スキャンの `LINE_PIXEL_RADIUS` でも記録する。テープは中心が距離目盛と合っているか確認する。
4. 複数フレーム、前後左右の見え方を照合し、半径と距離が単調になる実測点だけで表を更新する。範囲外は OUT／未知。10〜15cmの死角には点を登録しない。45cmが19cmと表示された実機例があるので、現行値を使ったまま停止距離の検証を済ませた扱いにしない。
5. 競技に戻すときは `BENCH_DISTANCE_CM = None` とし、テープや定規を外す。既知位置で距離と方位を再確認する。
