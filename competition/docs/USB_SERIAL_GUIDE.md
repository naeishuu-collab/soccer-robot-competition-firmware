# MAINのUSBシリアル確認

MAINの診断出力と操作入力には、基板のUSBコネクタからArduino-PicoのUSB CDC `Serial`を使う。`SerialPIO`はカメラUART用のGPIO 2/3に割り当て済みで、USBのCOMポートを作る機能ではないため追加しない。

## 書き込み後にCOMが見えない場合

1. BOOTSELボタンを離してからUSBを挿し直す。BOOTSEL中に見える`RPI-RP2`ドライブはUF2書き込み用で、シリアルポートではない。
2. デバイスマネージャーの「ポート (COMとLPT)」と「ユニバーサル シリアル バス デバイス」を見て、接続前後に追加された機器名を確認する。
3. データ通信対応ケーブルを使い、PCの別USBポートへ直結する。充電専用ケーブル、USBハブ、BOOTSELの押しっぱなしを避ける。
4. 既知のBOOTSEL UF2ドライブが見えるのに通常起動後にデバイスが一切現れない場合、COM番号の問題ではない。通常ファームウェアのUSB CDC列挙、USBケーブル／コネクタ、基板の再起動状態を切り分ける。
5. COMポートが現れたらArduino IDEのシリアルモニターでそのポートを選ぶ。速度は115200を指定し、開いてから最大1秒待つ。診断はホストがポートを開いたときに1秒周期で始まる。`s`は停止、`g`は走行許可、`i`は即時診断要求。

標準ビルドは明示的に`usbstack=picosdk`を選び、USB CDCを有効にする。書き込み成功だけでは通常起動時のUSB CDC列挙やシリアル出力を検証したことにならない。実機をUSB接続して確認するまでCOM復旧は未検証とする。
