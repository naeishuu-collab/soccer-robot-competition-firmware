# PENDING_HARDWARE 実機試験

この再構築では書き込み、通電、走行を実施していない。次の記録をそろえてから床上試験へ進む。

| 順序 | 試験項目 | 記録 |
| --- | --- | --- |
| 1 | 物理基板確認 | MCU刻印A/B、使用フラッシュ、DE、RS485 A/B、カメラ P4→GP3、GND |
| 2 | 車輪を浮かせた起動 | 起動・手動停止、カメラ／IR／MOTORの抜線、PWMゼロ、PWM20kHzと車輪極性 |
| 3 | RS485計測 | IR応答の最悪値、DE切り替え、停止指令の最悪遅延、衝突・CRCエラー、PWM更新間隔 |
| 4 | 追尾比較 | ZIPとこの版の角度・時間差・PWM、横切るボール、360°境界、単発の無検出、140付近の始動、反転待機が発生する頻度と影響 |
| 5 | OpenMV | 白線のみ・毎フレーム両色・間引き、撮像・走査・UART・ゴール・フレーム時間、FPS、照明別の黄青認識、校正、死角 |
| 6 | 停止距離 | PWM140・175・210、電池状態、床、応答遅延と惰走距離。正面・後方・旋回・曲線で機体の外周が白線へ到達するまでの余裕 |
| 7 | 退避 | ボールあり／なし、白線2方向、白線が死角へ入る場合、前後±175、トルク、機体形状と経路の余裕 |
| 8 | 経路候補 | 実測半幅・半長・最大停止並進距離・最大ヨー変位・盲領域で、同じライン配置を用いて既定判定とPC候補を比較 |
| 9 | 動力保護 | 反転の電流・温度・機体変位を記録。個別車輪だけの停止が生む合成移動を測る |

カメラ座標と車輪順の確認には、機体に前方向の印を付ける。床での初回は動力遮断を担当する人と短い走行枠を用意する。停止時は両PWM入力0。ハードウェアの遮断手段は実測で確認する。無検出から停止までの遅延と100／200msの期限は、測定した停止余裕と照合する。
