# 白線の確定・方向診断・実機確認

## API 6の方向別走行判定

基準は Draft PR #7 の 3636020433a8648d0c063e2348e0e3f70cd22ecd。ソフトウェア・ホスト試験のみ。OpenMV、MAIN、IR、MOTORの実機操作なし。

- `SAFE_MASK=0000` でカメラの退避フラグが立つと、実際のログと同じ `NO_SAFE_ESCAPE`、PWM全輪ゼロになる。前方の5本の観測が成立し、後方180°に近接白線があり、前方から±45°の位置に未確定候補がある合成画像入力では、旧版の未確定候補60°規制で前進を失った。新規制は未確定候補から45°未満。観測できた前方へ退避し、進行回廊に欠落がある場合は停止する。
- `SAFE_MASK=8007` と `REQUIRED_MASK=ffff` のログは、旧ZIP経路で再現した。直前版もこの入力の浅い前進PDはPWM160になる。今回、未計測の差動に対する全周安全時の例外と、直進代替のIR±45°条件を廃止した。左右両グループが同方向の指令で、観測済みかつ閉鎖されていない直進回廊があれば等速160。直進PDや実測済みの旋回範囲が通るPDは元の値を使う。実測未登録の純旋回および反対符号の差動に許可する退避がなければ停止。
- `CONFIRMED_BLOCK` は幅・隣接線の整合性で確定した白線、`SUSPECTED_BLOCK` は未確定候補、`HELD_BLOCK` は最近の確定記録。200msを過ぎた履歴は退避を繰り返さず、近づく方向を再観測まで保護する。履歴解除は同じ方向で2フレームと100msを要する。自己マスクに掛かった画素は既知の遮蔽として除外し、観測不能扱い。白飛びは反射の可能性があるが、画像上で区別できない反射は未確定のまま扱う。前後の回廊の放射線を減らしたり、暗さや白飛びで読めない方向を許可したりしていない。
- `LINE_PIXEL_RADIUS` と `DISTANCE_SOURCE=TABLE_ESTIMATE/UNKNOWN` を照合する。端の手前の参照画素も白・黒つぶれ・白飛びの場合は距離不明。45cmが19cmだった実測との差は残る。20・30・45cmの校正モードを維持する。距離モデルの推測値やTTCを速度制御に使わない。
- 現行のカメラUARTフレームは23バイト・CRC・版1。OpenMVファイルはAPI 6、BUILDは `rcj-openmv-competition-6`。白線スキャンとUARTを先に実行し、その後にゴール・描画・ログを処理する。緑色の既存処理はゴールの補助評価のみ。

回帰試験では前後UART/RS485、ゴールなし、非緑の床、横の未確定候補、近接白線・死角、追尾再開、観測欠落、手動停止とカメラ・IR・MOTORの通信断を検証する。前後両方の近接白線で出口がない場合は停止する。実機で全方向が閉じた原因の内訳は、RAW画像またはOpenMVの診断ログで照合する。

同じ8件の合成観測で比較して、不要停止3/4→0/4、非ゼロ指令の判定1/4→4/4、危険方向許可0/8→0/8、退避0/2→2/2、白線解消後の追尾復帰2/2→2/2。Pythonホスト上の方向判定は1,600回の平均で約14.4→11.9µs。センサー取得、UART、認識、ターゲット上のViper処理、実機のFPS・安全性を測った値ではない。

## API 5の走行優先改修（履歴）

基準コミットは e4badea37587bc1e83a2538570d39afa3608b5dc。現場の SAFE_MASK=0000 と Escape 指定で MAIN が NO_SAFE_ESCAPE を出す。SAFE は観測済みから白線規制を除いた結果で、ESCAPE はさらに白線から離れる前後方向に絞った結果。緑床未検出、ゴール未検出は停止理由に入らない。

現フレームの未確定近接候補に接近方向60°と近接退避105°の規制を重ねると、真の前方白線と少数の側方反射で全方向が閉じる。未確定候補の規制を接近方向60°に一本化した。確定済みの近接白線は保持を含め105°で扱い、後退・前進退避には観測済みで白線から離れる前後経路を要求する。合成試験では後退方向の観測がある場合に SAFE=0000 から後退許可へ変わり、後方の放射線を欠落させると停止する。実機で全ビットを閉じた内訳は同じ構図の新ログで照合する。

通常追尾で前方しか観測できない場合も、前方±45°のボール、両グループ正のPD、前方の安全ビットがそろえば等速PWM160を送る。前方ビットはカメラで前方±30°の5放射線を使って作成する。全周安全時は元のZIP PDをそのまま出力できる。未校正の旋回・横移動や必要方向の走査欠落では停止する。模擬UART・RS485統合試験で前方ビットのみの入力を再生し、MAINの送信バイトをMOTORで受理して4輪160を適用した。

利用者が確認した45cm先の白線は画像上では19cm表示。20・30cm定規線上のテープとは別の対象。現行表の走査開始は半径50px・18cmで、モデル上の19cmは約51pxに相当する。現行表による過小評価を確認したが、添付画像から元のセンサー半径は確定できない。端をまたぐ候補は接近規制を維持しつつ距離を未知にした。20・30・45cmを個別に測る手順は [距離校正](CALIBRATION_GUIDE.md#203045cmの距離校正) を参照。停止距離、ミラーの設定、白閾値、露光45msは実測まで既存値を使う。

OpenMVの4ファイルは API 5、BUILD=rcj-openmv-competition-5。1秒の自動ログで距離・半径・有効性と方向マスクの内訳を採取できる。通常運転で白線走査は毎フレーム1回、UART送信後にゴール検出、描画、ログを行う。校正ターゲット探索はベンチ専用。実機FPSと露光からモーター応答までの遅延は未計測。車輪を浮かせるMAINの試験用ビルドは [書き込みガイド](FLASH_GUIDE.md) を参照。

## API 4までの記録

## 入力と停止の再現

基準は Draft PR #7 の c9728df7c4168f1feb72709697212376003519a0。OPENMV (E:) の4ファイルは読み戻し、構文木と校正値を照合してから別フォルダへ保存した。

報告された 15°/18cm、Ready + Escape、SAFE=0000、IR受信正常、PWM 140,140,210,210 をそのまま模擬MAINに入力すると、NO_SAFE_ESCAPE・REQUIRED/BLOCKED=0101・出力ゼロを再現する。カメラ側の SAFE は OBSERVED から LINE を除いたもの。ESCAPE はさらに白線から離れる前後2方向と SAFE の共通部分。UARTの23バイト、CRC、方向ビット、PWMチャンネルの割当は従来どおり。後方を観測でき、白線がその方向を閉鎖しない合成入力では、MAINは後退退避を選ぶ。

実機の記録だけから、暗さ、白飛び、機体反射、保持中の別候補のうちどれが何ビットを閉じたかは確定できない。画像ファイルは今回の作業ツリーと接続ボリュームに含まれていなかった。下側の白が機体部品だったとの利用者報告はあるが、座標は推定で登録していない。

## ソフトウェアで特定した問題と修正

- 従来は1本の細い放射線が、同じ成分内の太い白まで確定に昇格させた。各線の幅と終端を独立評価し、距離校正の始端をまたいで白が続く候補や走査末端で切れる候補を確定から分離した。内側の追加画素は光学的な連続性の検査用で、距離の外挿に使わない。
- 距離が整合する複数の適格な隣接線で確定する。1画素幅でも3本連続で支持できる。曲線や画像端で確定できない場合も、その検出フレームで接近を制限する。確定区間と未確定区間は別の枠で描く。
- 保持期限切れの履歴が退避要求を出し続ける問題を修正。新しい危険がないとき、200msより古い履歴だけでは退避要求を送らない。過去に危険だった方向は観測で解除を確認するまで閉鎖を維持するので、別の安全経路が見える場合だけ追尾を再開できる。短い消失や急旋回の新しい候補を無視しない。
- FLOOR=ASSUMED を維持。緑LAB、緑領域の連続性・検出率は走行許可にもUNKNOWNにも入らない。緑はゴール形状の補助評価だけに残る。暗さ、白飛び、自己マスク、校正不成立では観測を有効にしない。
- 紫色の自己マスクをFULLで確認できる。LINE_SELF_MASKS の矩形、LINE_SELF_POLYGONS の頂点は元のQVGA座標で設定し、切り出しとQQVGAへ変換する。校正済み範囲を隠すマスクは該当方向を未知にする。前後の退避扇形が隠れるなら、部品・配線・鏡の位置を変えて観測範囲を再校正する。広げたマスクで白線を消して走行許可を作らない。
- 未計測の旋回外周や横・斜め退避を有効にしていない。観測が十分な通常のPD、既存の等速前進代替と確認済み前後退避を用いる。輪郭と停止距離を測って使用する既存Sweep設定は既定無効。通信断、手動停止、重大な異常、退避不能時の停止を維持。有効なIR応答でボールが見えないこととIR通信断は区別する。

## 判定を追う手順

1. 車輪を浮かせてOpenMVを実行し、BUILD=rcj-openmv-competition-4 を確認。4ファイルすべてが API 4 の同一版。MAIN、IR、MOTORは個別承認がある場合に更新する。
2. USBの 2 でFULL、i で診断。前方0°、右90°、後方180°、左270°と照合する。15°刻みのRAYSは白線検査方向、マスクのビットiは22.5°×i。OBSERVEDは各扇形すべての必要放射線を確認したときに立ち、UNKNOWNはその補集合。
3. SAFE=0000なら、DARK_MASK／CLIPPED_MASK／SELF_MASK、GEOMETRY_READYを確認。PRESENT_BLOCKは現フレーム、AMBIGUOUS_BLOCKは未確定近接候補、HELD_BLOCKは保持中の候補。CENSOREDは距離帯端で途切れた放射線。ビットは複数の理由に同時に現れうる。
4. NO_SAFE_ESCAPEなら ESCAPE_AWAY_MASK、ESC_UNKNOWN、ESC_LINE を確認。旧MAINの neither_forward_nor_reverse_clear と同じ決定で、最新版は全方向ゼロの場合に camera_reports_no_safe_sector も表示する。CAMERA_BAD、通信の鮮度、PWM_CALCULATED、PWM_AFTER_SAFETY、PWM_TRANSMITTED の順に見る。
5. 白線なし、前後左右、斜めと角、配線と金属反射、両側の白線、暗所と白飛びを確認する。方位と距離の正負が合ったら低速から前進・後退・斜め・急旋回・連続退避を試験する。高速度は停止距離の実測後。

## 比較と性能

24方向のViper走査は引き続き毎フレーム1回。色・点の座標・マスクは事前計算。端点の検査は候補がある放射線で実施する。UARTはゴール・描画・診断より先。ネイティブBLOBSとエッジ比較はベンチ専用。LED、描画、ゴールを含む同一照明で45/30/20/15/10/5ms、QVGA/QQVGA、BENCH_GAIN_DB、BENCH_RGB_GAIN_DBの結果を比較する。ベンチでは READY を送らない。旧閾値と高輝度候補の比較手順は [白線・動的試験](WHITE_LINE.md) を参照。出荷設定は45ms・既存LABのまま。

時系列の接近速度とTTCは参考情報。PWMを速度へ換算せず、実測速度・停止距離なしに早期退避設定を有効にしない。WHITE_SCAN、LINE_TO_UART、LINE_INTERVAL、FRAME の平均・P95・P99・最大を記録し、MAINのESCAPE_RX_TO_TXとMOTOR出力をロジアナで照合する。今の約22.2FPS・FRAME約32msは利用者測定。変更後の実機FPS、動作時の見逃し、露光からMOTORまでの総遅延は未測定。

合成回帰では、光学的に途切れた後方反射2放射線の確定が2→0、対向側に置いた実白線相当2放射線の確定は2→2。反射を理由に安全を解禁しないケースでは両版ともSAFE=0000を保つ。別の合成回帰では200msを超えた保持のみの退避要求が解除され、観測済みの反対方向が使える。これは合成条件の比較で、実機の不要停止率は未測定。
