# 停止・復帰条件

| 条件 | 競技経路の動作と復帰 |
| --- | --- |
| 起動・手動停止 | 初期出力ゼロ。入力がそろえば追尾可能。USB `s` の保持は `g` で解除 |
| `CAMERA_TIMEOUT` | 有効な新連番を最後に受けてから200ms、または未受信。更新で復帰 |
| `CAMERA_NOT_READY` | 構成・画像サイズ不一致等でREADYが立たない。校正後の有効フレームで復帰 |
| `CAMERA_SLOW` | 撮像を開始してから白線安全マスクを計算するまでが100msを超えたフレーム。次の期限内の安全フレームで復帰 |
| `NO_SAFE_ESCAPE` | 要退避で前後の安全な方向がない。見失いから200msで退避要求は終了し、危険方向は再観測まで閉鎖。観測済みの安全な経路があれば追尾へ復帰 |
| `IR_INVALID` | 角度範囲・終端等が不正。正常応答で復帰 |
| `IR_NO_REPLY` | 予約した12msに妥当な応答も異常フレームも届かなかった。正常応答で復帰 |
| `IR_TIMEOUT` | 正常なIR通信が未成立、または最後の正常応答から100ms以降に応答なし |
| `BALL_LOST` | 無検出、合成ベクトル相殺、または有効方位の期限切れ。新規ボール検出で復帰 |
| `PATH_BLOCKED` | 必要セクターが閉鎖・未観測で、確認済みの直進代替も成立しない。安全マスク更新、別のPD出力、または安全な退避が可能になれば復帰 |
| MOTOR `WATCHDOG` | 最後の妥当な指令から100msでPWMを0。新規指令と保護条件がそろえば復帰 |
| MOTOR `REVERSE_WAIT` | 符号が反転する車輪のPWMがゼロになってから200ms待つ。既定では待機中は4輪ゼロ。別途試験用のMAIN許可付き等速PWMだけを扱える |

ゴール角・信頼度・両色の未検出、LINE基板、BNO055、使用していない戦術は判定に入らない。床の全体比率による停止はない。進行に必要な一帯が観測できれば、他方の床色低下だけで直進を止めない。低FPS単独の停止はない。カメラの新規フレームが一時的に遅れても200ms未満は前の有効結果が使われる。安全情報自体が期限超過したフレームは `CAMERA_SLOW` で止まる。

25cm以内の白線は追尾より前後退避を優先し、有効なIR応答がありボールだけが見えないときも退避可能。35cm以内の白線は接近方向を閉じる。解除には30cm、2フレームおよび100msのヒステリシスを使う。白線が観測できず、前回の観測も古くなった場合は退避指令を終える。進行が必要な領域が依然不明であれば停止する。35cmより遠方の白線は表示でき、見えている安全扇形を閉じる理由には使わない。

ZIPのIR待ちは100ms。新経路は応答に12msのバス枠を設け、通信期限の100msと区別する。無検出時の45msは30ms周期の1回をまたぐ暫定上限で、通信の欠落や異常を隠さない。ZIP MOTORの250msは、角度透過の構成でローカルに停止する値。現行の直接駆動経路は通信断後の継続駆動を短く抑える100ms監視であり、再構築でも100msを採用した。ZIP原本には200msの反転待機がなく、再構築は現行MOTORの電気的保護を維持する。遅延・実車停止距離からこの閾値を確定する作業はPENDING_HARDWARE。

## 2026-11-28 追試：候補と保留の区別

カメラから前後両方の退避候補が届いた場合、現在の白線方位が前半分なら後退、後半分なら前進とする。方位不明または真横90/270度なら `NO_SAFE_ESCAPE`、`FALLBACK_REASON=AMBIGUOUS` で停止する。候補はカメラの観測・閉鎖・履歴を通過したものに限る。カメラの最近方位は確定した危険線とは限らず、実機ではこの選択の妥当性も確認する。前後どちらか一方しか候補がない場合はその候補のみを使用する。

`PATH_BLOCKED` の詳細は車輪ペアの未検証パターン、必要走行領域の閉鎖または未観測、未校正旋回を区別する。現行UARTのSAFEは観測不足と線による閉鎖を統合しているためMAINだけで両者を断定できない。OpenMVの `OBSERVED_MASK`、`UNKNOWN_MASK`、`CONFIRMED_BLOCK`、`SUSPECTED_BLOCK`、`HELD_BLOCK` を参照する。

白線が見えなくなっても履歴は直ちに消えない。退避要求は最後の近接観測から200msで終了するが、履歴の接近側は観測できて危険が解消されたことを2フレーム・100ms以上で確認するまで閉鎖される。観測不能が続く場合、閉鎖は期限なしで残り得る。条件により離れる側へ追尾復帰できるが、死角で白線が消えても実際に安全圏へ出たことを保証するものではない。

ホスト試験では遮蔽中の保持、再出現による解除待ち再開始、前後退避、無ボール時の退避、カメラ・IR断、手動停止、再観測後のCHASE復帰と模擬MAIN→MOTOR PWMを検証。実機での停止距離・死角・旋回軌跡と追尾復帰は未検証。未校正の旋回はPDをそのまま適用せず、同符号なら観測済み前後への直進代替、それ以外は停止する。横移動による側方退避は未実装。競技投入の判定は行っていない。
