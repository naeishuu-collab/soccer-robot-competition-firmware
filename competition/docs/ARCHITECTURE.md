## 基板と車輪

| 基板 | 設定と配線 |
| --- | --- |
| MAIN | Generic RP2350B / 2MBでビルド。UART0/Serial1 GP0 TX、GP1 RX、DE GP8。カメラPIO GP2 TX・GP3 RX。旧キッカー出力GP11はLOW固定 |
| IR | Generic RP2350A / 2MB。Serial1 GP0/1、DE GP2。TSSP58038はGP18〜29を順に30°刻み、LOWを数える |
| MOTOR | Generic RP2350A / 2MB。Serial1 GP1 RX、DE GP2はLOW固定。PWMは20kHz、8bit、走行の絶対値上限210 |
| OpenMV H7 Plus | UART3 P4 TX → MAIN GP3 RX、GND共通。P5の受信は通常経路で不要 |

A/B指定は既存の競技向けビルド表を採用した。ZIPのMAINとMOTORのコメントにはRP2354Bとあり、旧回路図ではMAINがRP2354Aと記録されている。書き込み前に実物の刻印と配線表を突き合わせる。

| PWM配列 | 車輪 | 論理＋ピン / 論理−ピン |
| --- | --- | --- |
| 0 | M3 左後 | 6 / 7 |
| 1 | M2 左前 | 12 / 13 |
| 2 | M1 右前 | 11 / 10 |
| 3 | M4 右後 | 9 / 8 |

ZIPの `M1〜M4` は上の配列順を示す記号で、実機資料の車輪名は位置を示す。現行資料の利用者試験は20kHz・PWM160で前後左右の移動を報告。PWM120ではトルク不足。今回の±175退避、140の始動、旋回時の向き、停止距離は実機確認待ち。

## 通信と時間

全リンクは115200、8N1。RS485はMAINが開始し、IRはポーリングにだけ返信。MOTORは受信専用。

| フレーム | 内容 |
| --- | --- |
| MAIN → IR | ZIP原本どおり `A5 5A 01 FE` |
| IR → MAIN | ZIP原本どおり `AA DIR_H DIR_L DET_H DET_L 55`。ベクトル相殺で強度が正の場合のみ角度 `FFFF` |
| MAIN → MOTOR | `D7 69`、4輪分の `PWM+210` を各16bit BE、代替PWM 1バイト（0または160）、CRC16 BE。13バイト |
| OpenMV → MAIN | `C6 6C`、連番、フラグ、16bit安全マスク、16bit退避マスク、白線角・距離、処理時間、黄・青の各角・信頼度・10ms単位年齢、版1、CRC16 BE。23バイト |

CRCはCCITT-FALSE（初期値FFFF、多項式1021）。カメラのフラグbit 0〜3はREADY、SLOW、ESCAPE、TARGET_BLUE。未検出角はFFFF、距離不明は255。安全マスクはbit 0から時計回りに22.5°刻み、0°は前。前後退避はbit 0 / bit 8。MAINが送信するPWMと、MOTORが出力したPWMは各基板で確認する。

IR周期の目標は30ms。4バイト要求は約0.35ms、5msサンプリング、6バイト応答は約0.52ms。DEの前後20µs、IR応答後にMAINが50µs待つ。受信待ちの間もカメラ・USB停止を処理し、完全なIR返信直後、または予約枠12msの終了後に最新の停止・走行指令を送る。MOTOR 13バイトは約1.13ms、カメラ23バイトは約2.00msの線上時間。MOTORへはPWM変更時または約30msごとに送信。IR期限が来てから先に送れる走行指令は1回。ゼロへの切り替えは優先する。これらはソフトウェア設計値と8N1換算で、IRQ、USB、実機の伝搬・遅延を含む最大値は測定待ち。

## 追尾と経路

ZIPのMOTORは角度受信ごとに `millis()` を読み、MAINが30ms周期で角度を中継した。新構成はMAINがIR返信受理ごとに同じ式を計算する。基準175、Kp 2.0、Kd 0.2、角度差は±180°補正、秒単位のD、turnは±250、非ゼロ出力は絶対値140〜210。MOTORは受信した値をそのまま適用する。中継分の到着時刻差やミリ秒境界はDに影響しうる。単発の無検出では直前の出力を最長45msだけ保持し、再検出時にDを初期化する。ZIPは無検出ですぐゼロだった。

前後の直進は、カメラが進行方向の±30°の放射線を確認した1ビットで判定する。全16方向という固定条件は使わない。差動のZIP出力は実測済みの掃引設定で経路を確認できた場合に使う。両PWMグループが同じ符号の差動で確認済みの直進経路があれば、等速PWM160へ切り替える。白線の近接退避は追尾に優先する。実測設定がない状態で反対符号または片側だけが動く差動には、直進代替を適用しない。

従来の全方位に回転を許す保証は、セクターごとの視界、視野下限、車輪の滑りと逆転、停止距離に依存する。近い側面白線からは、白線から105°以上離れる前後方向がなければ停止する。左右・斜めはPC上で出力の対応を検討した。PWM160の論理配列では右 `- + - +`、左 `+ - + -`、右前 `0 + 0 +`、左前 `+ 0 + 0`。右後・左後は反対向きの符号。退避の安全な軌跡とトルクが未確認のため、既定の退避用PWMは前後の±175。

独立したゴール攻撃補正の候補は、相手ゴール方位を観測し、その有効期限・品質・IR追尾・安全マスク・実測軌跡がそろう場合に限り、前進成分への小さな補正を比較できる。標準経路のPD、白線退避、PWMにはゴール入力がない。現時点で動作実装・補正値の採用は行っていない。

## 追尾の代替と逆転

実測設定を入れた場合、元のZIP PWM、旋回差を縮めたPWM、確認済みの等速PWMの順で経路を評価する。曲線は停止中の並進・旋回、機体半幅・半長、旋回による外周変位とセクター幅を含める。各値は最悪の遅延・滑りを含む保守値を実測する。観測距離は35cm以内。

試験用の EnableReverseBridge は既定 false。MAINに実測設定を入れて許可した場合だけ、MOTORは直前が全輪前向き等速のとき、反転の最初の35msまで確認済みの全輪+160を適用できる。反転が残っていれば全輪ゼロにして、ゼロ出力から反転車輪ごとに200msを計測する。代替許可の取り消しとゼロ指令を即時反映する。CRCで主指令と代替許可を同時に保護し、追加のRS485送信は発生しない。
