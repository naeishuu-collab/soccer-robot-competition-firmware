# MOTOR基板の設計資料・実機報告の照合

## 2026-11-17 最新のユーザー確認

- ユーザー指定の `soccer.zip` を完成版の設計資料として扱う。SHA-256は `D39977E63DE3C7CAC23FECA27BC9AF064628A34A17E64C260859601AC081DE4A` で、前回確認したアーカイブと同じ。
- 親基板のKiCad/BOMはRP2354A、MAX3485、TX/RX/ENおよび8本のPWMネットを示す。PWMネットとユーザー基準コードのGPIO配列は一致するため、MOTORビルド対象をRP2354A、GPIO範囲を30に合わせた。
- 子基板の回路図/BOMはIR4427系とMOSFETで、実機についてユーザーが確認したTB67H450×4とは異なる。実機のドライバーと4動作はユーザー報告を採用し、子基板図の出力論理をTB67H450コードへ流用しない。
- RS485の物理配線/終端/DE、4輪合成方向、E-stop/ARM、独立電源遮断は未確認。これらを根拠なく設定せず、PWM出力ゲートは閉じたまま。

## 以前の分類（2026-11-17のユーザー確認により更新）

以前は、製造基板が改善後でKiCadは旧版という前提で分類していた。ユーザーの最新指示に従い、ZIPを完成版として扱う。ただし、同ZIPの子基板回路はユーザーが実機確認したTB67H450×4と一致しないため、親基板の配線設計と子基板のドライバー回路を分けて記録する。

## 資料の範囲

提供されたsoccer.zipは33,932エントリー、SHA-256 D39977E63DE3C7CAC23FECA27BC9AF064628A34A17E64C260859601AC081DE4A。MOTOR親子のKiCad、BOM/Gerber/DRC、履歴、バックアップZIPを含む。直接エントリーと開ける入れ子ZIPにはファームウェアソースはなかった。子基板のBOM/回路図はIR4427PBF、TC7W系ロジック、MOSFET構成を示す。これは設計資料の記載で、実機の実装部品はユーザー報告のTB67H450×4として別に記録する。

## 現在のソフトウェア動作

- BoardConfig.ino: IN1={6,12,11,8}、IN2={7,13,10,9}、PWM周波数20kHz。ZIP親基板のRP2354AとPWM/RS485ネットを反映し、GPIO数30でビルドする。RS485物理通信は未確認。
- main/motor: MAINは `AA 04 [int16 little-endian ×4] XOR 55` を40ms周期目安で送信。MOTORは値域・チェックサム・終端・部分フレーム期限を検査し、300msで通信期限切れ、5/10ms加速、200ms逆転待機を実装。
- 車輪位置角・ローラー方向・電気的極性、ARM/E-stop/解除ピンと入力バイアスは未確認。`kMotorWheelConfigConfigured=false` と `kMotorHardwareConfigured=false` のためPWM出力無効。
- MAINは診断モード、競技ARM=false。Kickerのハードウェア/ポリシーもfalse。
- Arduino-Pico 6.3.2で現行4スケッチを4/4コンパイル。RS485通信、ホストC++アサーション実行、実機出力は未確認。

## ユーザー提供の実機成功コード

ユーザー申告の単体試験値を、TB67H450ソフトウェアドライバーの基準として採用した。Codexは実機を再通電・再測定していない。

| 値 | ソフトウェアでの扱い |
|---|---|
| TB67H450FNG×4 | ユーザー報告。ZIP子基板の回路図とは異なる。実装IC刻印/接尾辞との照合は未実施 |
| IN1={GP6,12,11,8}、IN2={GP7,13,10,9} | コード基準GPIO。並びはJ1右後/J2左前/J6右前/J7左後。実物との導通は未確認 |
| TX=GP0、RX=GP1、EN=GP2 | 参照コードの設定。RS485通信成功は未確認 |
| PWM=20kHz、範囲255、試験Duty=128 | 共通設定に反映。Duty上限128を越える値は拒否 |
| LOW/LOW停止、HIGH/LOW正転、LOW/HIGH逆転、HIGH/HIGHブレーキ | TB67H450のソフト出力表に反映 |
| 方向切替前にLOW/LOWを200ms | ランプ制御と出力アダプターの両方で反転/モード変更を待機 |
| ブレーキ切替 | SIOラッチを先にLOWに揃え、同じGPIOバンク内の2入力を一括変更。異なるバンクのペアは設定で拒否 |

[東芝 TB67H450FNG データシート](https://toshiba.semicon-storage.com/info/TB67H450FNG_datasheet_en_20201126.pdf?did=65346&prodName=TB67H450FNG)の入力/出力表は上記4モードと一致し、論理入力周波数上限400kHzの記載は20kHzを含む。LOW/LOWを保持すると約1msでStandbyに入り、LOW期間は0.7ms以下または1.5ms以上にするよう記載されているため、200msのLOW/LOW待機はStandby条件を満たす。実搭載品の接尾辞は未確認なので、回路一致や電流定格の根拠には使わない。

PWM設定・論理表はユーザー報告の単体試験条件です。J2左前の基準GPIOはIN1=12/IN2=13です。RS485候補はコードへ設定済みですが、実配線・通信は未検証。車輪運動学と物理ARMは未設定で、全モーターPWM出力はゲートで無効です。

## 実機を動かす前の照合

1. 実機MCU刻印とRP2354Aの一致を確認する。
2. 電源OFFで親基板のTX/RX/EN、PWM1..8、電源/GNDを導通確認する。
3. TB67H450×4のIN1/IN2対応と実装位置を確認する。ZIP子基板のIR4427回路は流用しない。
4. ARM/E-stop/FAULT解除と独立電源遮断の実配線・極性・バイアスを確認する。
5. RS485 A/B、/RE/DE、終端を確認した後、モーター電源なしでリンク試験を行う。
6. 車輪向きと極性を測定し、4輪合成方向を確認するまでは運動学設定を有効化しない。

実機書き込み、通電、モーター駆動は行っていない.
