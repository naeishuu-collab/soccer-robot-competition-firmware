## 結論

製造MOTOR基板は改善後の新版で、現在入手できるKiCadは改善前の旧版。新版の設計データは見つかっていない。今回ユーザー報告のPWMピン表と寸法は記録済みだが、その他の電気仕様・配線・安全回路はUNKNOWN。旧版情報はすべてLEGACY_REFERENCEで、旧版の不一致が新版にも存在するとも、解消済みとも断定しない。

## 現在のソフトウェア動作

- BoardConfig.h: PWMマスクはユーザー報告のGP6〜GP13、PWM周波数20kHz。GPIO数0、TX/RX/DE=-1、RS485確認=false、ハードウェア確認=falseを維持。
- motor/motor.ino: `kDriver`にJ2/J6/J7/J1の4ペアを記録。車輪位置角・ローラー方向・電気的極性は未設定。MOTOR RS485ピンが検証済みでないためUARTを初期化しない。
- MAINは診断モード、競技ARM=false。Kickerのハードウェア/ポリシーもfalse。
- 4輪の出力初期化・PWMは無効。GPIO表の登録は出力許可を意味しない。

## ユーザー提供の実機成功コード

ユーザー申告の単体試験値を、TB67H450ソフトウェアドライバーの基準として採用した。Codexは実機を再通電・再測定していない。

| 値 | ソフトウェアでの扱い |
|---|---|
| TB67H450FNG×4、RP2350系 | ユーザー報告。実装IC刻印/接尾辞との照合は未実施 |
| GP13/12、GP11/10、GP9/8、GP7/6 | 上表の車輪コネクターへの対応はユーザー報告。コードには記録するが出力は無効 |
| PWM=20kHz、範囲255、試験Duty=128 | 共通設定に反映。Duty上限128を越える値は拒否 |
| LOW/LOW停止、HIGH/LOW正転、LOW/HIGH逆転、HIGH/HIGHブレーキ | TB67H450のソフト出力表に反映 |
| 方向切替前にLOW/LOWを200ms | ランプ制御と出力アダプターの両方で反転/モード変更を待機 |
| ブレーキ切替 | SIOラッチを先にLOWに揃え、同じGPIOバンク内の2入力を一括変更。異なるバンクのペアは設定で拒否 |

[東芝 TB67H450FNG データシート](https://toshiba.semicon-storage.com/info/TB67H450FNG_datasheet_en_20201126.pdf?did=65346&prodName=TB67H450FNG)の入力/出力表は上記4モードと一致し、論理入力周波数上限400kHzの記載は20kHzを含む。LOW/LOWを保持すると約1msでStandbyに入り、LOW期間は0.7ms以下または1.5ms以上にするよう記載されているため、200msのLOW/LOW待機はStandby条件を満たす。実搭載品の接尾辞は未確認なので、回路一致や電流定格の根拠には使わない。

PWM設定・論理表はユーザー報告の単体試験条件です。`kMotorTestIn1CandidatePin=13` / `kMotorTestIn2CandidatePin=12`はJ2左前の試験由来として残し、4ペア表もコードへ反映しました。PWMマスクは4ペアのピンを示しますが、RS485、車輪運動学、物理ARMは未設定です。全モーター出力と自動起動は禁止しています。

## 新版を特定する手順

1. 製造番号/リビジョン、部品刻印、基板表裏写真、改版履歴を記録する。
2. 新版の承認済み回路図、PCB、BOM、製造Gerber、ネットリストを取得する。
3. 電源を接続せず、MCU・UART・RS485・電源・安全入力・PWMをネットごとに導通確認する。
4. 旧版と新版の差をレビューし、新版ERC/DRCを行う。
5. PWM/ARM/停止値は実部品資料と測定計画から決め、レビュー後に設定を追加する。

実機書き込み、通電、モーター駆動は行っていない.
