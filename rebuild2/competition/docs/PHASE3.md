# Phase 3 回り込み（シミュレーションのみ）

`RCJ_PHASE3_ORBIT` は既定 0。1 にした Arduino ファームウェアはコンパイルエラーになる。既存のPD、オウンゴール旋回、ゴール補正、停止・退避、b/y の動作は既定では従来どおり。OpenMV変更なし。

候補は既存の自陣ゴール危険条件と両ゴールの新鮮な観測を使い、140の横移動候補を最大600ms保持する。攻撃ゴールとボールが25度以内に揃う、ゴール情報喪失、白線・停止、600ms経過で終了し、2秒間再試行しない。停止・白線・通信・ボール喪失は既存判定が優先される。これは位置やボール距離を推定するものではなく、実際にボールの反対側へ到達した証拠にもならない。

横移動符号、床上軌跡と停止距離、IR強度と距離、ゴール誤検知、側方の白線・死角に対する軌跡安全は未校正。候補の車輪パターンと方向選択の対応は実機未確認。校正と側方安全判定の設計・検証が済むまでコンパイル禁止を解除しない。実機への書き込み・駆動は行っていない。
