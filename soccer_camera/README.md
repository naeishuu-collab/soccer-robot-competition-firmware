# サッカーロボット競技用ファームウェア

MAIN・IR・LINE・MOTORの4基板向けArduinoファームウェアと、ホスト側の検査コードです。

## 現在の判定

**自律制御のコードと段階別ガードを実装しました。床上AUTOは構成ゲートが閉じたままで、実機の自律動作は未検証です。**

- 起動時はLINE照会なしの `AUTO IR` 待機です。自動ARMは行いません。新鮮なIRでボールを認識した状態で `AUTO IR` → `ARM IR` を送ってください。`S` は停止指令を優先送信します。
- ユーザー報告では、MAIN→RS485→MOTOR→4輪の実機回転が成功しています。この作業では通電・書き込み・実機再試験をしていません。
- `AUTO`は車輪方向、LINE極性、競技ARMと安全入力の設定が確認されるまで拒否されます。`AUTO FLOOR`はさらに24個全てのLINE入力、LINE角度・デバウンス、BNO055校正・目標方位を必要とします。既知の故障LINE 6chと未確認設定により、この2モードは起動できません。
- `AUTO IR` では、近い壁・白線の回避を優先し、普段はIRでボールを追跡します。IRで近く正面にボールを確認したらカメラでゴールに整列します。カメラ／IRの通信が失効すると停止し、ARM中なら受信回復後に再開します。各輪PWMの上限は180です。非ゼロ指令の最大車輪値は少なくとも150になりますが、他の車輪は150未満になる場合があります。
- IRのRS485要求/応答、LINEのCRC付き要求/応答、BNO055のGPIO4/5・0x28・50kHz設定はソースから確認しました。IR/LINEの基板通信、センサー実測、BNO055実機動作は未確認です。
- BNO055の方位は通常AUTOの設定と診断に使用します。カメラやIRが失効したときの直進には使用しません。
- キックは、新鮮なIRの近接・正面判定と、カメラの攻撃ゴール整列判定がそろったときにMAIN GPIO11から出力します。壁・白線回避中はキックを抑止します。MOTOR側の通信ウォッチドッグは100 msです。 [キッカー回路レビュー](docs/KICKER_CIRCUIT_REVIEW_JA.md)
- 制御の流れは[動作ガイド](docs/CONTROL_GUIDE_JA.md)を参照してください。
- 4基板Arduinoコンパイル、C++/Pythonテストの最新結果は[テスト報告](docs/TEST_REPORT.md)を参照してください。

AUTOを開放する前に、物理安全回路、境界検出、車輪合成方向、通信断時の停止性能を実機で確認します。IR試験の手順は[セットアップ](docs/SETUP_JA.md)を参照してください。

提供されたCAD資料ではMAINのRP2354A/B設計が複数あり、現物を一意に識別できません。LINEの角度値は資料内のPCB上Q1〜Q24配置と1度丸めで一致しますが、PCBの現物一致・ソフトチャンネルとの配線対応・機体取付角度・極性は未確認です。MOTORは現行ファームウェアがTB67H450用である一方、資料内の子基板BOMからは一致するドライバー型番を確認できません。詳細は docs/LINE_SENSOR_LAYOUT_2026-11-16.md と docs/HARDWARE_CHECKLIST_JA.md を参照してください。

## 内容

- main/, ir/, line/, motor/: 各基板のスケッチ
- common/src/: ホストテスト用の共通コード原本。4基板のスケッチにも直接統合済み
- config/: GPIO検査用プロファイル
- tests/: テストソースと検査スクリプト
- docs/: セットアップ、[MAIN→MOTOR実機確認手順](docs/MOTOR_HARDWARE_TEST_JA.md)、コード解説
- openmv/: OpenMV H7 Plus用の競技スクリプト・表示・LAB計測・壁診断。共通設定と実測手順は [全方位カメラの校正](docs/OPENMV_CALIBRATION_JA.md) を参照してください。

コンパイル手順は docs/SETUP_JA.md を参照してください。ホストテストはWindowsのセキュリティ制御を変更・迂回せず、許可された実行経路でのみ実行してください。

UF2バイナリ、CAD ZIP、ローカル監査履歴やバックアップはこのリポジトリには含めていません。

## chase.zip の実機確認結果の統合

- IRのサンプリングは2 ms、最低検出数は3、GPIO18を0°、GPIO19〜29を反時計回りに30°刻み（送信角330°、300°…）として、予測値ではなく計測した方位を送ります。RELは引き続き未校正の相対値です。
- AUTO IRは全方位に平行移動し、ボール消失やIR通信断では停止します。MOTORの4番目はIN1=GPIO8、IN2=GPIO9で、100 msの通信タイムアウトと5 PWM/10 msの加速・減速を使用します。
- chase.zipとは通信形式が異なります。MAIN・IR・MOTORはこのプロジェクトの組み合わせで更新してください。LINEは未使用のままです。
- 統合後の車輪方向・IR方位・反転待ち・キッカーおよび停止は未実機検証です。車輪浮上、キッカー無効、即座にMOTOR電源を遮断できる状態から確認してください。競技AUTOゲートとカメラ校正ゲートは維持しています。

## 2026-11-20 の走行変更

AUTO IRは明示的なARM後に動作します。追跡はchase基準の最大PWM 180で、回避・旋回を含む非ゼロ指令は最大車輪値が150以上になるよう比率を保って補正します。小さい旋回指令も急な動きになり得ます。各車輪が150以上になる保証はなく、斜め走行の方向誤差も未検証です。MOTORは非ゼロ駆動PWMを各輪120〜200に制限します。加減速中も出力はこの範囲になり、車輪比率が変わります。USB手動指令は次の指令まで維持されます。床上試験前に車輪浮上で方向・停止を確認してください。
