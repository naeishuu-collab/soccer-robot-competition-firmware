# サッカーロボット：カメラあり版

## VS Codeで開く

親フォルダーの `サッカーロボット_カメラあり.code-workspace` をVS Codeで開くと、４基板・OpenMV・資料・テストが番号付きで表示されます。ビルド用フォルダーは非表示です。`ターミナル → ビルド タスクの実行` から４基板のコンパイルを実行できます。Arduinoのスケッチ名とフォルダー名は変更していません。

## 書き込みと運転

- MAINは `main/main.ino`、MOTORは `motor/motor.ino` を組で書き込みます。OpenMVは `openmv/goal_wall_navigation.py` を `main.py` として保存し、実機の `camera_calibration.py` を同じ場所に置きます。今回のカメラとMAINは8方向の床情報を含む新しいUART形式で通信します。
- IRは `ir/ir.ino` または実機確認済み `chase (3).zip` のIRスケッチを使えます。MAINは30 ms間隔でIRに問い合わせ、IRは要求ごとに5 ms測定します。
- 電源投入後、カメラとIRの通信が有効になり、ボールと進行可能な床を確認すると自動で追跡します。球を見失ったとき、進行先の床が確認できないとき、通信が途絶したときは停止します。条件が戻ると自動で再開します。起動・復帰の動作確認は車輪を浮かせて行います。

## 役割分担

- IRがボールの有無と方位を測ります。カメラが緑床・白線・黒壁を確認し、走行可能な方向と境界から離れる方向をMAINに送ります。OpenMV IDEには白線の方向数・最短距離・回避モードと、指定色のゴール枠が表示されます。
- MAINはボールへ向かう走行、境界回避、停止を選びます。球は機体で押す・弾く運用です。キッカー出力GPIO11は起動時にLOWにします。ゴール枠はプレビュー用です。
- MOTORは4輪出力を生成します。回避時に逆転が必要なら4輪を止めてから再開し、有効な指令が100 ms途絶えると出力を止め、次の有効な指令で復帰します。

白線25 cm・黒壁30 cmは暫定値です。白線距離はミラー軸からの距離です。実機で前後左右の検出と停止距離、車輪極性、IR・カメラ・MOTORの通信断、復帰時の自動再開を確認してから、出力と距離を調整してください。 [OpenMV校正手順](docs/OPENMV_CALIBRATION_JA.md)
