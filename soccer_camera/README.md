# サッカーロボット：カメラあり版

## VS Codeで開く

親フォルダーの `サッカーロボット_カメラあり.code-workspace` をVS Codeで開くと、４基板・OpenMV・資料・テストが番号付きで表示されます。ビルド用フォルダーは非表示です。`ターミナル → ビルド タスクの実行` から４基板のコンパイルを実行できます。Arduinoのスケッチ名とフォルダー名は変更していません。

現在の書き込み先は `main/main.ino`、`ir/ir.ino`、`motor/motor.ino` です。実機確認済み `chase (1).zip` の3基板を基礎にし、MAINへOpenMV境界回避と通信監視を追加しました。**3基板すべてを同じ版に更新してください。旧版とは通信形式が異なります。**

MAIN・IR・MOTOR・LINEはそれぞれ `.ino` 1ファイルでビルドできます。追加のプロジェクト独自 `.h` ファイルは必要ありません。LINEは現在のMAINでは使用しません。OpenMVは別途Pythonファイルが必要です。

AUTOモードとARM操作は使いません。起動後、ボールのIR情報と校正済みカメラの有効な情報を受けると追跡を開始します。ボール未検出、IR応答なし、カメラがWAITまたは通信期限切れの場合は停止します。ボール検出中の境界検出では、カメラが示す方向へ回避します。電源投入からの物理的な瞬時動作は保証できません。カメラの初期化・校正、各基板の起動、通信とモーター加速に時間がかかります。

OpenMVには `openmv/goal_wall_navigation.py` を `main.py` として、`openmv/camera_calibration.py` を同じ場所に保存します。このフォルダー内の校正値は未設定のため、使用するカメラの実測値を設定する必要があります。校正済みのOpenMVを既に使用している場合は、その実機の設定を確認してください。

LINE、BNO、キッカー、ゴール整列は今回の追跡用MAINでは使いません。キッカー出力GPIO11はLOWに初期化します。カメラの境界回避は統合後の実機検証が必要です。MOTORは通信が100ms途絶したら停止し、反転時の待ち時間と加減速を残しています。車輪角度・極性はZIP内で仮設定と記載されています。

詳しい変更点と書き込み先は [変更記録](docs/CHASE_2026-11-21_JA.md) を参照してください。旧版のスケッチとREADMEは `legacy_before_chase/` に保存しました。旧資料のAUTO操作、旧通信形式、旧テスト結果は今回のコードに適用しないでください。
