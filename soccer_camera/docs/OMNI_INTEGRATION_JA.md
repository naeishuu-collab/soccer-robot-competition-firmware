# 統合オムニ試験版（実機未検証）

基準 main c2be6fff1fda21310875551c3b55ba47766ee603、PR #3 の IR 保持と ZIP ロールバックを継承。標準 MAIN は ROBOT_UPGRADE=1, ROBOT_ZIP_COMPAT=0, ROBOT_RAW_IR=1, ROBOT_BNO_ENABLED=0。

| 基板 | 組み合わせ | 内容 |
|---|---|---|
| MAIN | main/main.ino | OpenMV v3 + ZIP 6-byte IR + 12-byte omni DRIVE |
| IR | chase (4) IR または ir/ir.ino | 115200、要求 A5 5A 01 FE、応答 AA + big-endian角度・強度 + 55。CRCなし |
| MOTOR | motor/motor.ino ROBOT_UPGRADE=1 | 115200、12-byte A5 03 ... CRC7、方向・速度・旋回・回避。ZIP MOTORとは互換なし |
| OpenMV | openmv/goal_wall_navigation.pyをmain.pyとして配置 | camera_calibration.py、competition_vision.py、必要に応じvisualize.py。PROTOCOL=2、wire v3 CRC16、115200 |
| LINE | 今回のカメラ構成では未使用 | 別基板のファームはビルド確認のみ |

MOTOR のみ4輪計算を実施。0度前・90度右、既存のPWM上限210、始動・反転待ち・タイムアウト100msを変更していない。速度/PWMテーブルと旋回極性は未校正。ZIPの左右差動PDは移植していないため、追尾性能の同等性は未確認。

カメラマスクから8方向の実現可能な候補を評価し、回避では旋回を禁止し MOTOR の厳しい誤差条件を使う。奇数の22.5度セクターだけが開いている場合、現状は候補がなく停止する。カメラの描画方向、実際の軌跡、ボディ半径と制動距離は未検証。回避中の実機安全は保証できない。カメラ期限200msと画像処理期限100msは変更していない。実処理周期は未計測。RAW IRの信頼度は測定されず、戦術ロジックへ互換用値を与え、テレメトリーの信頼度は0（未提供）とする。無応答の保持期限100ms、明示的な0強度では停止。共有バスはIR応答待ち中に送信しないが、期限を越えた遅延応答と送信の衝突は実機未検証。

BNOは標準無効。ROBOT_BNO_ENABLED=1でビルドするとI2Cを段階的に試し、校正・方位基準が有効な場合に補正する。絶対方位の基準がないと補正は開始しない。ゴール設定は既存のTARGET_GOAL=YELLOWを変更していないので試合前に確認する。

## 手順（書き込みは未実施）

1. 実基板のRP2350A/B刻印、Flash、GPIOと配線を確認。ZIPコメントはB、設計資料はAを示し食い違う。
2. 現在のMAIN・MOTOR・OpenMV設定を退避。MOTOR電源を切って、該当版のMAIN/MOTORをセットで導入。ZIP IRが既に稼働中なら変更不要。OpenMVにmain.pyと依存ファイルをコピー。
3. 車輪を浮かせ独立した電源遮断を準備。手動正逆転、4方向、対角、旋回のPWM/極性を低速条件で確認。ログの実送信方向と MOTOR の4輪出力を照合。
4. IR正面/左右/背後、ゴールなし、マスク各方向、白線回避と全閉停止、IR/カメラ切断と復帰、s/gを試す。カメラ画像・ロボットの前方向と安全マスクを照合。床上実験は安全領域・低速で制動距離を測定してから。
5. ロールバックは退避したMAINとZIP MOTORをセットで戻し、既存のZIP IRと従来OpenMVを使用する。片方だけ戻さない。

本変更は競技使用可否の判断ではない。実機でのセンサー方向、駆動特性、安全距離、ゴール精度、通信性能、追尾性能、衝突回避は未検証。
