# OpenMV H7 Plus 全方位カメラの校正

メーカーの標準レンズを通してミラーを撮影する構成を想定します。ミラーと機体を固定した状態で校正し、取付位置や解像度を変えたときは測り直します。

| スクリプト | 用途 |
|---|---|
| `goal_wall_navigation.py` | 競技用。カメラの `main.py` として保存し、同じ場所に `camera_calibration.py` を置く。 |
| `camera_only_display.py` | ゴールの輪郭、ミラー中心・リング・正面、壁／白線の検出点と現在のモードを表示する。UARTは初期設定で無効。 |
| `debug_thresholds.py` | ゴール候補数、面積とミラー領域での除外数、撮像設定、FPS、任意の位置のLAB分布を記録する。 |
| `wall_only.py` | 黒壁の候補と床を走査した境界点を比較する。診断用の旧形式 `0x02` と `0x14` を送信する。 |

診断用スクリプトを実行する場合は、`goal_wall_navigation.py` を元のファイル名で置き、`camera_calibration.py` も同じ場所に置きます。MAINと本番カメラのファームウェアは組で更新します。配線は OpenMV UART3 TX → MAIN GP3 (Serial2 RX) と GND共通、9600 bpsです。MAIN GP2はTXです。

## カメラの設定

1. `debug_thresholds.py` で画像寸法を確認し、`FRAME_SIZE` と `IMAGE_SIZE` を設定します。初期値はQVGAです。円が欠ける場合は、H7 Plusで使える解像度を選び直して測定します。
2. ピクセル座標で `MIRROR_CENTER` と `MIRROR_RING` を測ります。内半径の内側には機体の映り込み、外半径の外側には競技面より高い背景が主に入るよう、画像で確認します。次に前・右・後・左の目印を使って `FRONT_DEG` と `CLOCKWISE` を設定し、正面から時計回りに0°・90°・180°・270°となることを確認します。
3. 床上の目印をミラー軸から10、15、20、30、40、50、60 cmなどの既知距離に置き、写った半径を測ります。`GROUND_POINTS` に `(半径px, 距離cm)` の組を距離順に入力します。半径は増加、減少どちらでも使えますが途中で反転する設定は無効です。最初の点は18 cm以内、最後は50 cm以上が必要です。同じ距離を四方向で確認し、方位による差が大きい場合はミラーの中心と傾きを調整します。
4. `SAMPLE_ROIS` に映像上の黄・青・黒壁・緑床・白線の小矩形を設定し、LAB分布を計測します。静止時と旋回時、通常照明と陰で露出・ゲインを比べ、必要なら `EXPOSURE_US`、`GAIN_DB`、`RGB_GAIN_DB` を固定してから色しきい値を調整します。ゴール最小画素数はコート中央約110 cmと反対側約219 cmで確認します。機体の赤外照明は消灯した状態でテストします。
5. 試合の各ハーフ前に `TARGET_GOAL` を攻撃先の `"YELLOW"` または `"BLUE"` に設定して再起動します。ミラー・床面・攻撃色の設定がそろうまでは `WAIT` になります。

## MAINの設定と確認

- IRの `REL` は相対信号です。実際の競技球で、キックできる位置とその外側を複数の向きで測り、区別できることを確認して `main/main.ino` の `kOpenMvCloseIrSignal` を設定します。初期値0では `AUTO IR` は待機します。信号分布が重なる場合は、相対強度での近接確認を実機で再検討してください。
- キッカー出力を無効にして車輪を浮かせ、前後左右の境界に対して離れる向きへ指令が出るか、IR追跡が優先されるか、攻撃ゴール整列時に停止するかを確認します。カメラ／IR信号を切ったときと `S` の停止も試します。
- 競技用UARTの送信目標は50 ms間隔です。撮像から判定までに100 msを超えた場合は `WAIT` を送ります。MAINは最後の有効なカメラパケットから約200 msで失効させます。本番カメラの描画とUSBログは無効です。実際の受信間隔と状態はMAINの `DIAG OpenMV` 行で確認できます。

公式コートは白線内158×219 cm、外周182×243 cm、外エリア片側12 cm、ゴール幅60 cmです。近接回避は白線を直接走査し、黒壁を補助に使います。ペナルティエリアの白線にも同じ近接回避を適用します。白線の種類や機体の絶対位置の分類、見えない線を越えたあとの復帰は実機確認が必要です。18 cmの回避距離は機体寸法、見え方、制動距離に合わせて検証します。 [公式フィールド仕様](https://robocup-junior.github.io/soccer-rules/master/field_specification.html)
