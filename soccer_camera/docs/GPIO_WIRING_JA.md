# GPIO・通信の現状と未確認点

利用可能な設計資料とソフトウェア設定を区別する。表のGPIOは設計資料上の値で、実装基板やハーネスの導通確認ではない。

## 情報分類

- MAIN・IR・LINE: プロジェクト配列/設計情報と今回のユーザー報告を分けて記録。基板間ハーネスやすべてのGPIO導通を本作業で再測定していない。
- MOTOR: ZIP親基板のRP2354A/PWM/RS485ネットとユーザー報告のTB67H450 GPIO表を照合済み。物理導通・RS485・安全入力・電源遮断は未確認。ZIP子基板のIR4427系回路はTB67H450出力表と一致しないため混用しない。
- 基板間RS485ハーネス、終端・バイアス: UNKNOWN。

## 現行ソフト設定と設計資料

| 基板 | 設計上の候補 | コードでの状態 | 実機確認 |
|---|---|---|---|
| MAIN | RS485。BNO055 I2C SDA/SCL=GP4/GP5 | I2Cピンを設定。PIO UART不使用。校正オフセット未適用 | BNO055基本動作はユーザー確認。校正精度/ハーネスは未確認 |
| IR | UART TX/RX/DE=GP0/GP1/GP2。12入力=GP18〜29 | 12センサー、0番前方、30°刻み。旧6 byte応答を保持 | 全12入力の方向検知はユーザー確認 |
| LINE | UART候補GP0/GP1、DE=GP27。既存コード入力候補GP2〜25 | 18個有効/6個をマスク。極性/角度未設定、デバウンス無効 | 故障番号と向きはユーザー報告。GPIO導通/角度は未確認 |
| MOTOR | ZIP親基板: RP2354A、TX/RX/EN=GP0/1/2、PWM1..8。IN1={GP6,12,11,8}、IN2={GP7,13,10,9}。順序: J1右後、J2左前、J6右前、J7左後 | 12-byte MOTORフレーム受信を実装。Serial1/115200bps、MOTOR出力ゲートは閉鎖 | TB67H450×4の正転・逆転・停止・ブレーキのみユーザー確認。RS485、物理導通、4輪合成、極性、通信断停止は未確認。ZIP子基板回路は別構成 |

バス構成の論理:
MAIN → IR（実配線を照合）
MAIN → LINE（実配線を照合）
MAIN → MOTOR（ソフトウェア送信経路。物理通信は未検証）
MAIN ↔ BNO055候補 I2C GP4/GP5

MAINはIR/LINEを順次要求し、その合間にMOTORへ `AA 04 [int16 little-endian ×4] XOR 55` の12 byte指令を送信します。値は -255..255、256はブレーキです。MOTOR受信側の形式・範囲・チェックサム・終端・部分フレーム期限を実装しましたが、RS485実機通信は未検証です。基準コードのTX/RX/DE候補でUARTを設定しています。受信指令が300ms途絶えるとソフトウェアは停止へ移りますが、実機での停止動作は確認していません。

## 競技動作に進む前に必要な測定

1. 基板の型番・リビジョン、MCU刻印、端子番号と信号名を記録する。
2. 電源OFFでUART、DE、A/B/GND、終端、各電源レールを導通・短絡確認する。
3. MAIN/IR/LINE候補GPIOを資料と導通測定で確認する。
4. MOTOR親基板GPIO表を現物導通で照合し、TB67H450入力・RS485・安全入力の端子/極性を確定する。ZIP子基板のIR4427系出力回路はTB67H450の論理表に代用しない。
5. キッカー回路の充電禁止・残留電荷放電・定格を確認する。
6. センサー極性、物理角度、校正データを記録してから設定を有効化する。

ZIP子基板のIR4427系出力回路は、実機TB67H450×4の出力表として転記しない。
