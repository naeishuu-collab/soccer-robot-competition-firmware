# カメラあり版：書き込みと仕組み

> 2026-11-26の改善（新機能の切替、安全停止の変更、実機検査、ロールバック）は [UPGRADE_2026-11-26_JA.md](UPGRADE_2026-11-26_JA.md) を参照してください。

## 書き込むファイル

| 機器 | 書き込むファイル | 役割 |
|---|---|---|
| MAIN | `main/main.ino` | カメラとIRを受け取り、進む方向をMOTORに送る |
| IR | `ir/ir.ino` | 12個のIRセンサーからボールの方向を求め、MAINに返す |
| MOTOR | `motor/motor.ino` | MAINの指令を4輪のPWMに変換する |
| OpenMV | `openmv/goal_wall_navigation.py` を `main.py` として保存 | 白線を調べて回避方向を送り、ゴール候補を画面に表示する（ボールは扱わない） |
| OpenMV | `openmv/camera_calibration.py` を同じ場所に保存 | ミラー、色、露出、床の距離の設定 |

MAINとMOTORは姿勢補正を含む通信形式を共有するので、必ず両方更新します。`line/` はこの構成では使用しません。キッカーGPIO11はLOWに保ち、キックしません。

OpenMV UART3 TXをMAINのGPIO3へ、GNDを共通に接続します。カメラ通信はPIOを使いGPIO2をTX、GPIO3をRXとして9600bpsで動作します。MAINのGPIO0/1はRS485用です。

MOTORの前後左右の回転は、2026-11-27に実機で確認した組み合わせ（[手順書の0章](UPGRADE_2026-11-26_JA.md)）に合わせています。確認はテストコード・PWM160で行ったもので、このファームウェアは実機未確認です。斜め移動、旋回、BNO055補正の符号も実機確認が必要です。以前の版は右・左の指令でM3・M4が逆になるため、MOTORを書き直してください。

## 走行と停止

カメラとIRの通信が有効で、ボールの方向があり、カメラが走行可能な方向を確認できたときに動きます。ボールの方向は最後の検出から500msまで保持し、それ以降は停止します。起動後にボールを一度も検出していない場合も停止します。床が十分に見えない場合や白線の回避先を決められない場合は停止します。白線の回避方向がある場合はそちらに移動します。

カメラの有効な通信が200ms以上途絶えたとき、IRのRS485応答が途絶えたとき、またはMOTORが有効な走行指令を100ms受信できないときは停止します。条件が戻ると自動で走り出します。車輪の逆転時には200msの待ち時間があります。MAINのUSBで `d` か `s` を送ると停止指令になり、`g` で解除します。

MAINのシリアルモニタを115200bpsで開くと、約0.5秒ごとに `CAM=OK mode=2 IR=OK ball=0 DIR=0 PWM=160` のような状態が出ます。`CAM=NO` はカメラ通信がない状態、`IR=NO` はIRからの応答がない状態、`ball=360` は現在有効なボール方向がない状態です。`DIR` は最後に送った走行方向、`PWM` は走行指令の強さです。

## BNO055（一時無効）

BNO055が使用できないため、現在はMAINの `BNO_ENABLED = false` で無効にしています。センサーを初期化・読み取りせず、姿勢補正を加えません。再び使う場合はGPIO4/5、アドレス0x28の配線と動作を確認したうえで `true` に変更し、車輪を浮かせて補正方向を確認してください。

BNO055が無効の間は角度をシリアル表示しません。有効時の `heading` は現在の角度、`relative` は起動後の基準からの回転角です。提示されたテストコードの固定オフセットや急変除去は現行MAINには適用していません。

## ミラーと色

`MIRROR_AUTO_DETECT = False` のとき `MIRROR_CENTER` と `MIRROR_RING` の固定値を使います。`True` にすると起動時に自動検出を試し、検出できなければ固定値を使います。`RING: AUTO` は自動検出、`RING: CONFIG` は設定値です。

`GROUND_POINTS` はミラー中心からの画像半径と実際の床距離を対応させます。枠が変わっても値は自動換算されないため、白線距離は実測で確認してください。床や距離が設定と合わないと白線を見逃すことがあります。設定が不正な場合は画面に `CHECK GROUND_POINTS` などを表示し、停止します。

青・黄のゴール枠は画面表示用です（`competition_vision.py` も一緒にコピーします）。ボール検出はIRだけで、カメラは扱いません。色や形は光・鏡像の歪みで誤認識します。`BLUE: NO C… S… R…` のCは青候補、Sは小さく除外、Rはミラー範囲外で除外した数です。

## 最初の確認

車輪を浮かせ、すぐ電源を切れる状態で、通信断の停止、復帰、各車輪の回転、BNO055の補正方向を順に確認します。BNO055のI2C実通信、モーター極性、補正の強さ、白線距離、青・黄の検出は実機で調整が必要です。特に通信が復帰すると自動で動き出します。
