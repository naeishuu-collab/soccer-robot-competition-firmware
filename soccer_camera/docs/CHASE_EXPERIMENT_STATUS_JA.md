# 競技用PD追尾・白線検出の試験版

このコードは車輪を浮かせた実機試験用。競技投入や床上走行に必要なカメラ方向、車輪極性、機体寸法、停止距離、露出は未検証。

通常のMAINは従来経路 `ROBOT_ZIP_TRACK=0`、OpenMVは `COMPETITION_TEST=False`。試験版MAINは `ROBOT_ZIP_TRACK=1`、`ROBOT_TEST_MAX_PWM=160` でビルドする。出力上限を160とするためZIPの175〜210の実出力とは異なる。試験版は新MOTORの4輪PWM指令に依存し、旧MOTORと混ぜない。

試験版OpenMVは `goal_wall_navigation.py` を `main.py` として保存し、`competition_vision.py`、`fast_scan.py`、`camera_calibration.py` を同じ場所に置く。試験版の校正設定は `COMPETITION_TEST=True`、`FORCE_FLOOR_OK=True`、`DEBUG_STATS=False`、`GOAL_DEBUG=False`。実機の色・ミラー・露出の校正値は上書き前に必ず保存する。

競技用走査は緑・黒の色分類を使用せず、白線および各方向の大まかな明暗・画素変化を評価する。極端な暗さ・明るさや単調な視界は閉じるが、任意の遮蔽物を検出できるわけではない。しきい値は未校正。撮像異常・通信断・古い安全情報では停止する。白線退避は前後方向のみで、安全な前後方向がなければ停止する。旋回中は全周の安全マスクを要求する。

非ブロッキングUARTは実機で部分送信と受信タイムアウトを確認していないため、試験版でも `EXPERIMENTAL_NONBLOCKING_UART=False`。本試験版のUART送信は完全には非ブロッキング化されていない。FPS、送信周期、取得遅延は未測定。

## 書き換え・確認手順

1. 実機の各基板の現行ファームウェアとOpenMV内の全ファイル・校正値をバックアップし、チップ印字がRP2354A/Bのどちらか確認する。異なる型番向けのUF2を使用しない。
2. 車輪を浮かせ、キッカーを無効化し、電源を切った状態で試験を準備する。実機への書き込みは使用者が行う。
3. 対応するMOTOR用UF2、次にMAIN用UF2を書き込み、OpenMVに4ファイルをコピーする。IRは既存のZIP形式と互換なら変更不要。LINEはこの構成では未使用。
4. 無人状態での自動再開を避け、手動停止の操作を確認する。電源投入後、前後・左右のPWM極性、ボール角度の変化、白線と見えない方向、IR断、カメラ断、MAIN-MOTOR断、手動停止、復帰を確認する。必ず出力波形と実際の動きを照合する。
5. OpenMV IDEで `DEBUG_STATS=True` とし、同一環境の撮像・走査・UARTの時間と更新周期を計測する。露出45ms設定のまま30FPS達成を前提にしない。

元に戻す場合はMAIN・MOTOR・OpenMVを基準コミット `8ae5cb0de858bcf9c0815c4c727d288ae198a882` の対応する版に組で戻し、保存した実機固有校正値を復元する。既存のIRも保存版に合わせる。
