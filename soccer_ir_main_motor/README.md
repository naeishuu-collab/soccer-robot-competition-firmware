# サッカーロボット（カメラなし）

このフォルダーは、カメラを使わず **MAIN・IR・MOTOR** でボール追跡するファームウェアです。LINE は別基板用の任意スケッチで、現在の AUTO IR では使いません。MAIN・IR・MOTOR はこのフォルダー内の同じ版を組にして書き込んでください。

添付 chase (1).zip は方位とモーター配置の資料として使っています。ZIP側とこのプロジェクトではRS485通信形式が異なるため、ZIPのMAIN/IR/MOTORを混ぜて書き込まないでください。

## ZIPの資料を反映した点

- IRのセンサー番号は反時計回り、送信方位は「前0°・右90°・後180°・左270°」にそろえました。GPIO18/21/24/27をそれぞれ前/左/後/右として扱います。
- MOTORのチャンネル順は RIGHT_REAR, LEFT_FRONT, RIGHT_FRONT, LEFT_REAR、軸角は前方基準のZIP表から Motion 座標へ変換しました。
- これらの角度と極性は仮設定です。ZIPのコードが動いたことは、車体が正しい方向へ動く確認にはなっていません。kMotorWheelConfigConfigured=false と kCompetitionArmed=false を維持しています。

## ビルドと確認

Arduino CLI と Raspberry Pi Pico/RP2040 Arduino core が必要です。workspaceを開き、既定ビルド（Ctrl+Shift+B）で MAIN・IR・MOTOR を順にコンパイルできます。LINEは任意で、タスク一覧から単独または4基板一括でコンパイルします。

「テスト: 方位・車輪設定」は標準Pythonの unittest でセンサー方位・オムニ車輪符号・スケッチ間の設定一致を確認します。

common/src/ は各 .ino にインライン化された共通コードの参照元です。コンパイルでは各スケッチ側のコピーが使われるため、共通設定を変更するときは4つのスケッチと一致させてください。config/gpio_profiles.json は配線メモで、ビルド時に自動読込されません。

## 実機での確認

- コードのコンパイル成功だけでは、実際の進行方向、モーター極性、RS485配線は確定しません。現時点では「コードが起動した」までで、「正しい方向に動いた」確認は未完了として扱います。
- AUTO IR の出力上限はPWM 16/255ですが、車輪は回ります。車体を浮かせ、キッカーを無効にし、すぐにMOTOR電源を切れる状態で各車輪の向きと4輪合成を確認してください。
- 方向を確認するまでは競技用AUTOを有効にしないでください。カメラもLINE境界検知もないため、フィールド端で自動停止できません。
- IR近接キックしきい値 kIrKickCloseSignal は0のままです。測定と安全確認なしにキック条件を有効化しないでください。

## スケッチ

| フォルダー | 基板 | 用途 |
|---|---|---|
| main/ | MAIN (RP2354B) | IR統合・走行制御 |
| ir/ | IR (RP2354A) | 赤外線ボール方位 |
| motor/ | MOTOR (RP2354A) | 4輪モータードライバー |
| line/ | LINE (RP2354B) | 白線検知（任意） |
| common/src/ | 共通コードの参照元 | 各スケッチへインライン化済み |
| config/ | GPIO設定メモ | ビルドには未使用 |
