# サッカーロボット（カメラなし）

このワークスペースは **MAIN・IR・MOTORの3基板だけ**でAUTO IR追跡を動かす構成です。カメラ基板・LINE基板は接続も書き込みも不要です。MAIN・IR・MOTORはこのフォルダー内の同じ版をそれぞれの基板へ書き込んでください。

添付 chase (2).zip は方位・MOTOR配列・車輪軸角の資料として使っています。ZIP側とこのプロジェクトではRS485通信形式が異なるため、ZIPのMAIN/IR/MOTORを混ぜて書き込まないでください。

## ZIPの資料を反映した点

- IRのセンサー番号は反時計回り、送信方位は「前0°・右90°・後180°・左270°」にそろえました。GPIO18/21/24/27をそれぞれ前/左/後/右として扱います。
- MOTOR配列順は [M4=RR, M1=LF, M2=RF, M3=LR] = [RR, LF, RF, LR]。IN1=[6,12,11,9]、IN2=[7,13,10,8]をMAIN・MOTORの両方に反映し、コンパイル時static_assertで固定しています。
- ZIPの車輪軸角[45,225,315,135]（前0°・右90°）をMotion座標[x=右,y=前]の[45,225,135,315]へ変換。車輪計算の符号は[+1,+1,+1,+1]、MOTORの出力極性は `kMotorReverseOutput` で設定し、現行値は全輪 `false` です。両設定は別レイヤーです。
- これらの角度と極性は仮設定です。ZIPのコードが動いたことは、車体が正しい方向へ動く確認にはなっていません。kMotorWheelConfigConfigured=false と kCompetitionArmed=false を維持しています。

## ビルドと確認

Arduino IDE で `main/main.ino`、`ir/ir.ino`、`motor/motor.ino` をそれぞれ開き、Raspberry Pi Pico/RP2040 コアの **Generic RP2350** を選びます。Chip Variant は MAIN が **RP2350B**、IR と MOTOR が **RP2350A** です。MAIN は Adafruit BNO055 ライブラリも使います。

3スケッチの `src` は `common/src` への相対シンボリックリンクです。コピーや圧縮の際は、フォルダー構成とリンクを保持してください。共通コードは各スケッチのビルド時に参照されます。

## IRセンサー個体差の校正

ZIPの10 cm・12方向キャリブレーションをIR方位推定に適用しました。照合が十分確かなときは30度区分の校正角を使い、それ以外は従来の連続ベクトル推定へ戻ります。10 cm以外は未検証です。追加データ取得と適用範囲は[IR校正手順](docs/IR_CALIBRATION_TSSP58038_JA.md)を参照してください。シリアルモニターの `CAL START` はCSVログ取得用です。

## MAIN → MOTOR の走行指令

自動走行では、MAIN が左右・前後・旋回の正規化指令と走行モードを送り、MOTOR が4輪のPWMへ変換します。フレームは12バイトの `AA 05 [左右] [前後] [旋回] [モード] XOR 55` で、各フィールドは16ビットの下位バイトが先です。各軸の ±1 は ±16384、モードは FLOAT が1、FLOOR が2、IR が3です。XOR は末尾の2バイトを除く先頭10バイトから計算します。USBの手動4輪指令 `M` と全輪停止には従来の `AA 04` フレームを使います。IR 基板も `AA 05` を読み飛ばせる版へ更新してください。

## 実機での確認

- コードのコンパイル成功だけでは、実際の進行方向、モーター極性、RS485配線は確定しません。現時点では「コードが起動した」までで、「正しい方向に動いた」確認は未完了として扱います。
- 起動時はシリアル入力なしで AUTO IR の自動ARM待機に入り、鮮度のあるボール方位を最初に受信した時点で追跡を開始します。ボール未検出・IR通信切れでは停止し、再検出で追跡を再開します。USBから何か入力すると起動時の自動ARMを取り消します。停止にはMAINで `S` または電源スイッチを使います。
- AUTO IR の非ゼロ指令はPWM 120～210です。走行指令をピーク210へ正規化し、非ゼロ値を最低120にします。起動時のAUTO IRはIRボール追跡試験モードで、競技用AUTO FLOOR/FLOATとは別です。競技用モードは車輪設定・安全入力・境界検知の確認が終わるまで無効です。
- MAIN→MOTOR確認は車輪を浮かせ、キッカーを無効にして、MAINのシリアルモニター（115200bps）で `M 128 0 0 0`（RR）、`M 0 128 0 0`（LF）、`M 0 0 128 0`（RF）、`M 0 0 0 128`（LR）を一つずつ入力し、各車輪とINピンを照合します。現在の極性設定では、全輪の正指令がIN1側を駆動します。各確認後は`S`で停止します。
- MOTOR基板のシリアル診断で output_ready=1 と command_active=1 を確認します。RS485_rx が0のままならMAIN/MOTOR間の配線・DE・トランシーバーを確認し、受信が増えても command_active が0ならフレーム形式または破棄カウンターを確認してください。command_active=1で出力がない場合は、MOTORドライバーのVM電源、GND、IN端子からドライバーまでを確認します。
- 方向を確認するまでは競技用AUTOを有効にしないでください。カメラもLINE境界検知もないため、フィールド端で自動停止できません。
- IR近接キックしきい値 kIrKickCloseSignal は0のままです。測定と安全確認なしにキック条件を有効化しないでください。

## スケッチ

| フォルダー | 基板 | 用途 |
|---|---|---|
| main/ | MAIN (RP2350B) | AUTO IR・走行制御 |
| ir/ | IR (RP2350A) | 赤外線ボール方位・校正プロファイル |
| motor/ | MOTOR (RP2350A) | 4輪モータードライバー |

カメラなしの AUTO IR 構成では上記3スケッチをビルドします。LINE スケッチは別構成用です。
