# TSSP58038 12ch 個体差キャリブレーション

## 目的と前提

TSSP58038は、38 kHz付近の変調赤外線を受けるデジタル受信モジュールです。出力は検出時LOWで、照度をアナログ電圧として返しません。このファームの `detectCount[i]` は2 msの窓でGPIOを読み、LOWだった回数を数えた相対値です。物理距離や絶対光量ではありません。

受信器の差だけを比較するには、送信源の搬送波・バースト幅・繰返し周期、距離、角度、高さ、電源、周囲光をそろえます。まず競技で使うIRボールを送信源に使います。別のLED発振器を使う場合、搬送波周波数だけでなくボールのバースト波形も合わせてください。TSSP58038の周波数応答は38 kHz中心で、仕様グラフの±5%帯域の上端は約39.9 kHzです。対象ボールの公称40 kHzはその境界にわずかに外れるため、感度差の補正より先に実球で検出を確認します。これは直ちに使用不可という意味ではありません。

## ログモードの使い方

1. `soccer_ir_main_motor/ir` のスケッチをIR基板へ書き込み、USBシリアルモニターを115200 bpsで開きます。改行設定はLFまたはCR/LFにします。
2. `CAL DARK` を送ってから `CAL START` を送ります。CSVヘッダーと約100 msごとの生データが出ます。校正中は通常のUSBデバッグ表示だけを止めます。IR計測とRS485応答は続きます。
3. IRボールを遠ざけるか送信を遮り、周囲光だけの値を最低100行記録します。シリアル出力をログ保存できるモニターを使うか、テキストへコピーしてCSVとして保存します。
4. `CAL SIGNAL` を送り、実球を固定治具に置きます。距離・高さを固定し、ロボット正面から見たボール方向を `CAL ANGLE n`（0〜359°）で記録します。
5. 各センサーの正面方向にボールを順に置き、各方向で最低100行ほど取ります。方向は現在の角度表に合わせ、0, 330, 300, 270, 240, 210, 180, 150, 120, 90, 60, 30度（センサー0〜11）です。ボール中心までの距離と高さを全位置でそろえ、`CAL ANGLE` のあとに記録します。
6. `CAL STOP` で終了します。条件ラベルは各行に入るので、1つのログに暗状態と信号ありの両方を記録できます。CSVとして使うときは `CAL_HEADER` 行と `CAL` 行を残します。

シリアルコマンド:

```text
CAL START
CAL DARK
CAL SIGNAL
CAL ANGLE 0
CAL ANGLE 330
CAL STOP
```

`CAL DARK` / `CAL SIGNAL` と `CAL ANGLE` は記録ラベルを変更します。測定値を補正したり、IR追跡の設定を書き換えたりはしません。

## CSV列

ヘッダーは `CAL_HEADER`、データ行は `CAL` で始まります。

| 列 | 意味 |
|---|---|
| condition | `DARK` または `SIGNAL` |
| angle_deg | テストしたボール方向。未設定は `-1` |
| sample_ms / seq | サンプル終了時刻 / 行番号 |
| window_us | 実測したサンプリング窓（目標2000 µs） |
| sweeps | 12ピン一巡を行った回数 |
| total_low | 12センサーのLOW読み取り回数の合計 |
| s0〜s11 | GPIO18〜29各ピンのLOW読み取り回数 |

センサーごとの比較には `s_i / sweeps` を使います。`sweeps` が少ない行や計測窓が大きく外れた行は比較から除きます。サンプリング回数はCPUやシリアル出力の影響を受けるため、生の `s_i` だけを別ファームの値と比較しません。

## 補正係数の決め方

各センサー `i` について、暗状態の `s_i/sweeps` の中央値を `dark_i`、そのセンサーの正面方向でSIGNAL時に記録した同じ比率の中央値を `signal_i` とします。

```text
response_i = max(0, signal_i - dark_i)
reference = response_i の有効なセンサーの中央値
gain_i = reference / response_i
```

応答がほぼ0のセンサーには係数を作らず、配線・向き・はんだ・送信源を先に確認します。初回は係数を0.5〜2.0に制限し、左右の既知方向で方位が改善することを確認してから制御コードに反映します。係数が頻繁に上限へ張り付くなら、環境光や治具条件が不安定です。実測値なしに既定のゲインを決め打ちしないでください。

補正をコードに反映する段階では、現行の各 `detectCount` を暗時応答分だけ差し引き、ゲインを掛けた12値でベクトル方向を計算します。RS485フレームやカメラなしの制御部は変えず、同じ角度・距離のデータで補正前後を比較します。

## ハード確認

- Vishayのデータシート上のピン配置は1=OUT、2=GND、3=VS、動作電源は2.0〜5.5 V、検出出力はLOWです。実装基板のピン順と電圧をテスターで確認し、受信器とMCUのGNDを共通にします。
- 蛍光灯や太陽光の影響を見るため、DARKログは実際に使う場所・照明条件で取得します。暗室だけの校正値を明るい競技場へそのまま適用しません。
- データシートの伝送距離値は指定IR LED、電流、試験波形の条件付きです。今回のボールやロボットで同じ距離が出る保証ではありません。
