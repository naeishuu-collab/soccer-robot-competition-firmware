# TSSP58038校正データの適用

## ZIPから取り込んだ測定データ

`RCJ-IR-SUB-10cm-USB.zip` の `Mac/calibration.json` には、GPIO18〜29について、背景1条件と10 cm・30度刻み12方向の測定統計が入っています。各条件24サンプルです。元データは [calibration_10cm.json](../ir/calibration_10cm.json)、実行時プロファイルは [ir_profile.h](../ir/ir_profile.h) に保存しています。

測定から各センサーの正面応答の最大平均を比較すると、0.316〜0.322の範囲でした。正面ピークのセンサー間差はおよそ±1%なので、大きな個別ゲイン補正は入れず、12方向で得たセンサー配列全体のパターンを使って方位を補正します。

## 現行IRファームでの動作

- GPIO18〜29を一括読み取りし、方向推定での読み取り時刻差をなくしました。校正用には10 µs間隔のLOW状態を隣接サンプルで確認し、50 ms分を集計します。
- 集計率をZIPの10 cm・12方向プロファイルに照合します。背景を除き、誤差と次点との差がしきい値を満たした場合だけ、校正済みの30度区分を方位に使います。
- プロファイルが一致しない場合は、従来の連続ベクトル方位へ戻します。距離センサーはないため、照合処理が10 cm以外を判別するわけではありません。別距離でもパターンがしきい値内に入れば校正角を使う可能性がありますが、10 cm以外では未検証です。
- RS485の現行通信形式は維持しています。ZIP内のUSBレーダー用スケッチやUF2は、このプロジェクトへ置き換えていません。

30度刻みの分類なので、境界付近やボールが移動中は照合を拒否して従来方位へ戻ることがあります。ZIP内の校正JSONは24サンプルの平均・標準偏差だけを含み、独立した実機検証データはありません。実機で正面・左右・背面を確認してください。

## 追加データを取得する方法

新しい距離・照明・ボールで再校正したい場合は、IR基板のシリアルモニターを115200 bpsで開き、次の手順でCSVを記録します。`CAL START` はデータ採取を始めるだけで、実行時プロファイルを変更しません。

1. 送信源なしで `CAL DARK`、続けて `CAL START` を送信し、背景を最低100行記録します。
2. `CAL SIGNAL` に切り替え、距離・高さを固定した実球を配置します。
3. 各センサーの正面位置で `CAL ANGLE n` を送信し、方向ごとに100行以上記録します。GPIO18〜29の角度は順に `0, 330, 300, 270, 240, 210, 180, 150, 120, 90, 60, 30` 度です。
4. `CAL STOP` で終え、出力の `CAL_HEADER` と `CAL` 行をCSV保存します。

```text
CAL DARK
CAL START
CAL SIGNAL
CAL ANGLE 0
CAL ANGLE 330
CAL STOP
```

CSVの `s0`〜`s11` はGPIO18〜29のLOW読み取り回数、`sweeps` は一括読み取り数です。`s_i / sweeps` で同じファーム内のセンサー応答を比較します。暗状態との差を引いたうえで、同一距離・各方向のデータからパターンを作ります。10 cmデータから遠距離の校正値を推定しないでください。

## 信号波形の注意

TSSP58038は38 kHz付近の変調赤外線を受けるデジタルモジュールで、アナログ照度や距離を直接出力しません。検出時LOWです。Vishayの代表感度試験は38 kHzの10周期以上（約263 µs）のバーストを使います。一方、プロジェクトで参照しているボールは40 kHzを8周期（約200 µs）送る仕様です。40 kHzは38 kHzの±5%上限約39.9 kHzをわずかに超え、バースト長も試験条件より短いため、実球での受信距離・安定性を確認してください。この差だけで受信不能とは断定できません。

TSSP580..のピン配置は1=OUT、2=GND、3=VS、動作電源は2.0〜5.5 Vです。実装基板の電圧・ピン順を確認し、MCUとGNDを共通にします。
