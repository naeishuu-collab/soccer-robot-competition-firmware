# サッカーロボット競技ファームウェア

現在のカメラあり版は [soccer_camera/README.md](soccer_camera/README.md) を参照してください。MAIN・IR・MOTORは同じ版を組み合わせ、AUTO・ARM操作を使わず、IRと有効なカメラ情報がそろったときに追跡します。LINEは現在未使用です。

VS Codeでは `サッカーロボット_カメラあり.code-workspace` を開くと、４基板・OpenMV・資料・テストが整理されて表示されます。カメラなし版は `サッカーロボット_カメラなし.code-workspace` を開いてください。動作条件と書き込み先は[変更記録](soccer_camera/docs/CHASE_2026-11-21_JA.md)を確認してください。

`soccer_ir_main_line/` と `soccer_ir_main_motor/` は過去のカメラなし版です。以前のAUTO制御を含み、現在のカメラあり版とは通信互換ではありません。`legacy_before_chase/` と `chase_camera/` も旧版・作業途中の保存であり、書き込み用ではありません。

カメラの校正が必要です。統合後の実機動作は未確認のため、車輪を浮かせ、動力をすぐ切れる状態で方向・停止を確認してください。

## 競技候補

指定基準コミットからの候補ではMAINの既定経路をZIP PD追尾にし、カメラが確認した0°/180°の直線退避はIR未応答でも行います。旋回時の全16セクター確認は車輪配置・停止距離が確定していないため維持します。停止条件・復帰条件・PENDING_HARDWARE項目は[停止条件](docs/STOP_CONDITIONS.md)を参照してください。

参照された `chase (4).zip` 原本はリポジトリ内にありません。ZIP PDの10,000入力テストは独立転記との比較であり、原本ソースとの一致確認ではありません。
